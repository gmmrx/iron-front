# Command panel material v2

Superseded after visual feedback. Framed panels now use the individually generated
v3 parts documented in `../command_panels/PROMPTS.md`; this material is retained
as a non-destructive source iteration, not used by the active panel skin.

Generated with the built-in image generation tool, using the supplied politics
screen as a material/style reference. Saved without resampling at the returned
1254×1254 resolution: `command_gunmetal_v2.png`.

The runtime draws this grain at a fixed texel scale, underneath separate thin
inset borders and the existing brass corner fittings. It is scoped to framed
game panels. Existing icons, portraits, HUD and navigation assets are retained.

## Full prompt

Use case: stylized-concept.
Asset type: production seamless dark metal UI material texture, NOT a screen mockup.
Input image1 is STYLE REFERENCE ONLY: match the nearly black blue-charcoal satin metal inside its politics/research section cards. Do not copy any of the interface or symbols.
Generate a square opaque perfectly front-facing material swatch, uniformly lit, edge-to-edge seamlessly tileable on all four sides. Extremely fine, sophisticated blackened steel micrograin and restrained dark-blue patina. Average sRGB around #152024 with subtle tonal variation within #11191d to #1c272b. It must read mostly smooth at normal UI size and reveal refined microtexture only close up, suitable behind dense ivory text in a WWII grand strategy game. Very faint naturally irregular hairline tool marks only, never large scratches, rust or recognizable stains.
No frame, gold, borders, ornaments, rivets, silhouettes, letters, text, buttons, portraits, bevels, gradients, vignette, highlights or perspective. No fabric weave, stone, leather or noisy grunge. Maximum available native resolution, square, clean rich understated material; premium precise military instrument panel finish.
